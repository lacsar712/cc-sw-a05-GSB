# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

**环境温度必填门禁**：提交校准单前必须在「温感台」登记环境温度；缺温拒收并提示“缺温”，温度随单冻结、事后改温表不得改旧单；巡检员可见温列但不可提交。

## 验收

1. calibrator 登录后，菜单进入「温感台」可见必填说明、温栏与已锁温度清单；总览另加环境温度列。
2. 种子「氦灯-587」合格、「汞灯-546」超差，均带冻结温度 24.5℃。
3. **缺温拒收**：不填环境温度直接提交，被拒收且明确写明“缺温”。
4. **有温随单冻结**：在温栏填 24.5 后提交，单子收下；再次打开该单，环境温度仍是 24.5℃。事后改温表/改旧单温度会被数据库触发器拒绝（`环境温度已随单冻结，禁止修改旧单温度`）。
5. 再提交超差样条，先待处理再出超差。
6. inspector 能看到环境温度列，但温栏只读、不能提交（服务端对缺权提交返回 403）。
